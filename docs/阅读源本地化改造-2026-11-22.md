> 背景：用户希望把 kmoe / 次元狗 / 轻小说文库的"下载源完全搬进应用"，让用户看到最新最热、点进去在线看、或下载到应用默认目录后应用内观看。
> 本轮按实测与合规评估，分三档落地。**未提交、未发布、不碰 android。**
> 调研证据：`C:/Users/Administrator/Downloads/_anime_reverse_work/` 下三份报告。

## 二、本轮改动

### 1. 轻小说文库单章在线阅读（新适配器）

- 新增 `utils/media-sources/wenku8-reading.js`（独立文件），注册进 `reading.js` 的 ADAPTERS。
- `catalog()` 用 sitemap 的 `/book/{id}.htm` 做目录；`chapters()` 从详情页按 `/novel/\d+/\d+/\d+\.htm` 正则抽章节；`read()` 取 `#content`、白名单清洗（去 script/on* 事件）、返回 `isHtml`。
- **GBK 解码不用额外修**：`engine.decode()` 已按 meta charset 处理，实测标题/正文中文正常。
- 安全：`assertWenkuHost` 仅 https + `wenku8.cc` 白名单 + 拒绝 IP 直连。
- 实测：详情页拿到"文学少女"1 章、正文 2319 字。

### 2. 次元狗资源索引适配器（外链源）

- 新增 `utils/media-sources/ciyuanhou-reading.js`，注册进 ADAPTERS，`external: true`。
- `catalog()` 解析首页 72 个 `article` 卡片（标题/href/封面/日期）；因 cheerio 对双下划线复合 class 匹配不稳，改用 `filter(attr includes)`。
- `chapters()` 返回详情元数据 + 一个「前往原站查看网盘资源 ↗」伪章节；`read()` 返回带原站链接的提示页——**不抓正文、不抓网盘链接**。
- 安全：仅 https + `acgndog.com`/`acgmh.com` 白名单 + 拒绝内网。
- 实测：36 条最新、封面与标题正确。

### 3. KMoe 下载到漫画目录（完整链路）

- 新增 `utils/kmoe-download.js`：`assertSafeDownloadUrl` 仅 https + `dl*.koobone.com` 白名单 + 拒绝内网；`safeName` 清洗书名；`saveEpubToComicFolder` 流式下载签名 EPUB 到 `config.comicFolders[0]/KMoe/{系列}/{卷}.epub`，用 path-guard 校验路径在允许的扫描目录内，校验 EPUB 的 PK 魔数（避免把错误页写成 epub），**以 vol_seriesid+卷号去重，不存签名直链**。
- `routes/cloud.js` 新增 `GET /api/cloud/kmoe/koobone/save`：kooboneLookup 拿签名 URL → 调用 saveEpubToComicFolder → 返回保存路径；未导入书库返回 `code:2` 提示先去 KOOBONE 导入。
- `public/js/app.js`：kmoe 卡片新增「💾 存漫画库」按钮，单卷直接下载/多卷弹选择器；保存后触发一次静默扫描入库，提示到漫画库阅读。

### 4. 增量更新进度显示（截图反馈的问题）

- `utils/updater.js::startIncremental` 改为四阶段（checking/downloading/verifying/ready），下载阶段带真实字节百分比（downloadPatchBytes 加 onProgress），ready 带明确 note。
- `public/js/app.js`：`downloadIncrementalUpdate` 发起后 600ms 轮询阶段状态；`showUpdateProgress` 显示 `增量更新 2/4 ①检查✓ → ②下载68% → …` + 已用秒数；就绪时提示"即将自动重启、无需操作；20 秒后仍未重启请手动关闭重开"。
